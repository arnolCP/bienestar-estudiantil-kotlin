# Bienestar Estudiantil en Consola - Kotlin

Programa de consola desarrollado en **Kotlin** como parte de la práctica de fundamentos del lenguaje. Permite registrar a varios estudiantes y consultar su nivel de estrés mediante un menú interactivo.

## Descripción
El programa permite al usuario:
- 📝 Registrar estudiantes (nombre, edad y nivel de estrés).
- 👀 Ver todos los estudiantes registrados.
- 📊 Ver un resumen final y salir.

El menú se repite hasta que el usuario elige la opción de salir.

## Conceptos de Kotlin utilizados
1. **Listas mutables:** `mutableListOf` para guardar a varias personas.
2. **Variables:** `val` (no cambian) y `var` (sí cambian).
3. **Entrada de datos:** `readln()` y `toIntOrNull()`.
4. **Estructuras de control:** `while`, `when`, `if / else` y `for`.
5. **Interpolación de cadenas:** `$variable` dentro de `println()`.
